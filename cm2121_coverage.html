#Finding
1 The business team signal needs a rule. 1,581 Likely pairs were found because they share an xDM business team — same name, same firm, same team. Without an ExactContactBusinessTeam rule in PROD, Semarchy will never auto-merge them. Consider adding this rule to CM-2121 or a follow-on ticket.

Methodology

How this analysis was built

Correction — ExactContactBusinessTeam

The first version of this analysis attributed coverage to an ExactContactBusinessTeam rule (score 100). That rule was listed in CLAUDE.md, which was extracted from a UAT configuration XML (ClientMaster [2.5] (10).xml, UAT Main branch 2). The PROD SemQLMatcher does not contain this rule. All corrected numbers remove it from the existing-rule coverage calculation.

Data source

The 3,083 pairs come from the PB/Wires duplicate workbook (Snowflake, run 2026-08-05). Pairs were blocked on shared CRD, shared email, and shared xDM business team, then scored with Jaro-Winkler and classified into Definite / Likely / Name Collision.

Rule simulation

Each PROD rule was approximated using golden-level columns in the CSV: shared phone count, shared email count, shared biz-team count, ZIP match flag, address exact-match flag, name equality, firm equality, state equality. Rules requiring publisher-pair data (ExactEmail SFDC_NG exclusion, ExactFNLNSfxZip PREQIN-only) are modeled as their widest possible condition — so coverage counts for those two rules are upper bounds.

Threshold model

Auto-merge threshold for confirmed goldens is strictly > 90 (mergeThresholdMergingConfirmed = 90). Rules scoring ≤ 90 create suggestion groups but do not auto-merge. "Below threshold" in this analysis means score 85 — these create suggestions but require steward confirmation unless R8 is deployed.

Business team gap

The 1,581 uncovered Likely pairs share an xDM golden-level business team. In Semarchy, match rules fire on staging/master-level data — the ExactContactBusinessTeam rule (if it existed) would need the business team membership to be populated at the master record level before golden consolidation. Adding such a rule to CM-2121 is a potential next step.
